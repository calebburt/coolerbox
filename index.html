Privacy Policy for DCC Utils

Last updated: August 17, 2026

DCC Utils is a browser extension designed to customize and improve the Schoolbox portal experience.

1. Data Collection

We do not collect, store, transmit, or sell any personal information, browsing history, or analytics. Your data remains strictly yours.

2. Local Storage

Any preferences you configure—such as theme colors, layout choices, and widget settings—are saved locally on your device using your browser's built-in local storage. This data never leaves your computer.

3. Third-Party Services

The extension includes a widget that fetches a daily text from a public API (bible-api.com). When this happens, a standard web request is made to their servers, but absolutely no personal information or tracking identifiers are sent with it.

4. Changes to this Policy

If the extension's features change in a way that affects privacy, we will update this policy.

5. Contact

If you have any questions about this privacy policy, you can reach out via the Support tab on the Chrome Web Store page.
